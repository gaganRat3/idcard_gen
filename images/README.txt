LOGO IMAGE INSTRUCTIONS
========================

Place your actual logo image files in THIS folder (images/).

Required file names (exactly as listed):
  - logo-vivah.svg   (or .png)  → VIVAH / BhudevMatrimony logo
  - logo-bhudev.svg  (or .png)  → BHUDEV Network.com logo
  - logo-nri.svg     (or .png)  → NRI VIVAH logo

Currently, placeholder SVG logos are included.
To replace them with real PNG logos:
  1. Copy your PNG files into this images/ folder
  2. Rename them: logo-vivah.png, logo-bhudev.png, logo-nri.png
  3. In index.html and app.js, change the .svg extension to .png

Recommended image size: 90 × 30 pixels (3:1 ratio)
Format: PNG with transparent background works best.

For best PDF quality, use high-resolution PNG images (e.g. 180×60px or 270×90px).
